Release Notes

V2.8.0_May/2026

New Features
  • Added two pixel formats: MV_FG_PIXEL_TYPE_BayerBRGG8 and MV_FG_PIXEL_TYPE_HB_BayerBRGG8 .
  • Added two members to the structure MV_FG_BUFFER_INFO : nFirstLineEncoderCount and nLastLineEncoderCount .

V2.7.0_November/2025

New Features
  • Optimized the registration of external buffers. Supported dynamic registration of external buffers after calling MV_FG_StartAcquisition().
    • Supported calling MV_FG_AnnounceBuffer() or MV_FG_AnnounceBufferEx() to register external buffers after calling MV_FG_StartAcquisition().
    • Supported calling MV_FG_RevokeBuffer() to clear the registered buffers after calling MV_FG_StartAcquisition().
    • Added MV_FG_RegisterImageCallBack() for registering a callback to get images when external buffers have been registered.
  • Add 0x0182 to indicate errors in event packet buffers.
  • Optimized event related features.
    • Supported registering events for multiple handles of a frame grabber at the same time in a single-process environment. In a process, if you call MV_FG_RegisterEventCallBack() for handle A and handle B respectively to register the same event M, both handle A and handle B will receive event M at the same time.
      Note
      When registering the same event multiple times for the same handle, the previously registered callback function and custom information will be overwritten.
    • SDK supported receiving CoaxPress camera event.

V2.5.0_November/2024

New Features
  • Added APIs for image grabbing, image rendering, and image saving of an image over 4 GB.
    • Supported rendering an image over 4 GB in OpenGL rendering mode by calling the added API MV_FG_DisplayOneFrameEx() and setting enRenderMode to OpenGL.
      Note
      To achieve this feature, a specified graphics card is required.
    • Supported saving a TIFF/PNG image over 4 GB by calling the added API MV_FG_SaveTiffToFileEx() / MV_FG_SavePngToFileEx() respectively, which is achieved via the added data structure MV_FG_SAVE_TIFF_TO_FILE_INFO_EX and MV_FG_SAVE_PNG_TO_FILE_INFO_EX .
    • Added an extended structure of input image information MV_FG_INPUT_IMAGE_INFO_EX , supporting input of image over 4 GB.
  • Added an API MV_FG_PurpleFringing() and a corresponding data structure MV_FG_PURPLE_FRINGING_PARAM for correcting purple fringing occurred in high-contrast or low light areas to enhance image quality. You can set different values of nKernelSize and nEdgeThreshold in MV_FG_PURPLE_FRINGING_PARAM to change the effect of purple fringing correction.

V2.3.0_August/2023

New Features
  • Synchronized SDK functions of Linux and Windows system, and updated Linux version number to 2.3.0 together with the Windows version.
  • Added support for controlling CoaXPress/XoFLink/Camera Link/GigE Vision frame grabbers in multiple processes.
  • Added APIs for initializing SDK resources and releasing SDK resources: MV_FG_Initialize(), MV_FG_Finalize()
  • Added and updated C++ sample programs.
Optimized:
  • Optimized frame grabber events' performance and stability.
  • Supported compatibility with Intel 12th processor.
  • Added compatibility with Ubuntu 22.04 and kernel 6.1.
  • Optimized compatibility with some third-party cameras.
  • Optimized compatibility with older versions of frame grabber firmwares.
  • Fixed bugs from previous versions.
Reorganized:
  • Reorganized Programming Guide, displaying API calling flows by different function modules, and added some sample codes.
