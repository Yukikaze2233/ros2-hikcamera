◆ MV_FG_HB_Decode()

MV_FGCTRL_API int __stdcall MV_FG_HB_Decode ( IN IMAGEHANDLE  hImage,
IN OUT MV_FG_HB_DECODE_PARAM *  pstDecodeParam 
)

Lossless decoding.

Parameters
hImage[IN] It refers to the image handle. You can use the handle of frame grabbers, cameras, or stream channels.
pstDecodeParam[IN][OUT] It refers to the lossless decoding parameter structure.
Returns
Returns MV_FG_SUCCESS for success, and returns corresponding Error Code for failure.
Remarks
Decode the lossless compressed stream data from the camera into raw data.
The API can also parse the watermark information of the real-time image of the current camera. (If the input lossless stream data is not from the current camera, or is not real-time stream, then exception might occur during watermark parsing.)
The handle of the current camera is needed to parse watermark information. The frame grabber handle or the stream handle can only be used for lossless decoding.

◆ MV_FG_ReconstructImage()

MV_FGCTRL_API int __stdcall MV_FG_ReconstructImage ( IN IMAGEHANDLE  hImage,
IN OUT MV_FG_RECONSTRUCT_INFO *  pstReconstructInfo 
)

Reconstructs images.

Parameters
hImage[IN] It refers to the image handle. You can use the handle of frame grabbers, cameras, or stream channels.
pstReconstructInfo[IN][OUT] It refers to the reconstruction information.
Returns
Returns MV_FG_SUCCESS for success, and returns corresponding Error Code for failure.
Remarks
Supports image rotation, image flipping, and image segmentation, but requires specified preconditions such as:
Image rotation and image flipping:
  • Supported pixel formats: MV_FG_PIXEL_TYPE_Mono8, MV_FG_PIXEL_TYPE_RGB8_Packed, and MV_FG_PIXEL_TYPE_BGR8_Packed.
Image segmentation:
  • Supports any pixel formats.
  • Should be used with MultiLightControl node of the scan camera. If the value of MultiLightControl node is 2, the camera will reconstruct 2 images with different exposure values into one image (with its height the sum of two images) and send it to the upper layer application.
    If this API is called then and the value of reconstruction method is set to RECONSTRUCT_MODE_SPLIT_BY_LINE_2, the image from the camera will be later divided to 2 images with two corresponding exposure values.
Note
If line scan camera is not used or MultiLightControl node of line scan camera is disabled, the image reconstructing function will not work. The image will be divided into n images by line, each of these n images with the height 1/n of the original image (determined by enReconstructMode).
