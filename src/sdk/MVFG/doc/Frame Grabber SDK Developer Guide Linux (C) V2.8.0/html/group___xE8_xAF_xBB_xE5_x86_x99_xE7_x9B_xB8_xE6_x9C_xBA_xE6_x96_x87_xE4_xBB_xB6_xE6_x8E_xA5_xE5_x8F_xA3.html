◆ MV_FG_FileAccessRead()

MV_FGCTRL_API int __stdcall MV_FG_FileAccessRead ( IN PORTHANDLE  hPort,
IN OUT MV_FG_FILE_ACCESS *  pstFileAccess 
)

Reads file data from the camera.

Parameters
hPort[IN] It refers to the handle of the object to which the parameter belongs; the object can be either a frame grabber or a camera.
pstFileAccess[IN] It refers to the file access structure.
Returns
Returns MV_FG_SUCCESS for success, and returns corresponding Error Code for failure.
Remarks
Reading might fail if you do not have the operation permission of the files.
File names on frame grabbers and cameras come from the feature node UserSetSelector.
